# SEM2 Wiki

SEM2 is a research-stage package for structural equation models.

Package documentation is maintained with the code in [`docs/source`](https://github.com/causal-design/sem2/tree/main/docs/source) and built with Sphinx. Use that as the authoritative package guide and API reference; this wiki is a short entry point, not a duplicate manual.

The documentation is configured for [GitHub Pages](https://causal-design.github.io/sem2/), available once a repository administrator enables Pages and the first deployment succeeds. Build and preview it locally using the [instructions in `docs/README.md`](https://github.com/causal-design/sem2/blob/main/docs/README.md), which also describe the one-time Pages setup.
